# MedicK 实用背包 v2.0.3

在背包底栏加入仓库、全部存入和商人按钮，并提供可折叠的快速传送菜单。

## 功能

- **仓库**：在任意位置打开仓库。
- **全部存入**：把背包物品批量存入仓库，并遵循词缀仓库页规则。
- **商人**：在任意位置打开 NPC 商人，默认隐藏，可在设置中开启。
- **快速传送**：按阵营、地下城和枢纽分组，只前往角色已经解锁的传送点。

## 操作

- 所有按钮位于背包面板。
- 点击“快速传送”标题可折叠菜单。
- 点击分组标题可折叠对应目的地。

## 安装

把 `medick_Terrible_Inventory.dll` 放入：

```text
Last Epoch\Mods\
```

## 注意

仓库、商人和传送功能更适合离线模式。线上模式可能受服务器校验影响。
