# MedicK 技能冷却 v1.0.2

在角色头顶显示正在冷却的技能图标。

## 功能

- 从游戏运行时读取技能图标。
- 显示冷却遮罩、就绪状态和按键标签。
- 自动识别键盘、Xbox 和 PS5 输入。
- 可拖动图标组，支持逐技能槽开关和自定义标签。
- 支持手柄按键选择器与移动锁定。

## 操作

| 按键 | 功能 |
|---|---|
| `Home` | 打开或关闭设置面板 |
| 拖动标题栏 | 移动设置面板 |
| 移动 → 拖动图标 → 锁定 | 调整悬浮图标位置 |

## 安装

把 `medick_CooldownTracker.dll` 放入 `Last Epoch\Mods\`，进入游戏场景后按 `Home`。
