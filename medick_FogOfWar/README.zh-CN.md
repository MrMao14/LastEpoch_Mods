# MedicK 战争迷雾 v1.0.2

在游戏设置中加入六级地图视野控制。

| 等级 | 名称 | 效果 |
|---|---|---|
| 0 | 失明 | 隐藏小地图 |
| 1 | 困难 | 小地图可见，但不揭示新区域 |
| 2 | 受限 | 默认揭示范围的 69% |
| 3 | 正常 | 游戏默认视野 |
| 4 | 侦察 | 默认揭示范围的 3 倍 |
| 5 | 神谕 | 揭示半径 600，覆盖整个区域 |

## 安装

把 `medick_The_fogOFwar.dll` 放入 `Last Epoch\Mods\`，然后在游戏设置中找到“战争迷雾”。

## 注意

视野类功能建议只在离线模式使用。已经揭示的区域通常要进入下一个区域后才会重新计算。
