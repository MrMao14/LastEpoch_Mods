# MedicK 物品提示 v3.1.2

为物品提示、词缀和地面掉落标签增加层级、评级和过滤器信息。

## 功能

- 每个词缀显示层级和 S/A/B/C/F 浮动评级。
- 支持徽章、纯文本、左侧、右侧和行尾布局。
- 按住 `Alt` 展开完整数值范围和制作信息。
- 在地面物品名称后显示层级和评级标签。
- 在物品提示中显示命中的过滤器规则编号。
- 设置面板、下拉选项和模组生成的提示文本均已汉化。
- 解析同时兼容英文与中文“层级/范围”文本。

## 设置

在游戏设置中打开“物品提示”分类。完整选项也会保存到：

```text
UserData\medick_Terrible_Tooltips.cfg
```

## 安装

把 `medick_Terrible_Tooltips.dll` 放入 `Last Epoch\Mods\`。

## 兼容性

- 可独立使用，不依赖 KG 的旧模组。
- Melon 名称仍为 `Terrible Tooltips`，用于兼容 Fallen Star 的模组检测。
- 不要同时启用其他功能重复的工具提示模组。
